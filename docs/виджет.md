# Виджет календаря на домашний экран

Средний виджет: слева календарь месяца с точками на занятых днях, справа —
что стоит на сегодня. Тап открывает приложение на «Дне».

Виджет **только читает**. Он берёт из облака ту же копию, что синхронизирует
приложение, и ничего не записывает: домашний экран — не место для решений.

## Что понадобится

1. **Scriptable** — бесплатное приложение из App Store.
2. **Вход в облако** в самом планере: виджет читает данные оттуда, а не с
   устройства. Без синхронизации показывать ему нечего.

## Установка

1. Открой `widget/lifeos-widget.js` из этого проекта и скопируй его целиком.
   На телефоне удобнее открыть файл на GitHub и нажать «копировать».
2. В Scriptable нажми **+**, вставь код и назови скрипт `Life OS`.
3. На домашнем экране: долгий тап → **+** → Scriptable → **средний** виджет.
4. Тап по добавленному виджету → **Script**: `Life OS`.
5. В планере: Настройки → «Виджет на экран» → **Показать код доступа** →
   скопируй. Вставь его в поле **Parameter** у виджета.

Готово. Первый раз виджет обновится сразу, дальше — когда iOS решит; обычно
это несколько раз в час. Тап по нему открывает приложение.

## Про код доступа

Это токен твоего входа в Яндекс ID. Отдельного, узкого ключа для виджета у
Яндекса нет, поэтому код открывает те же данные, что и вход: кто его получит,
увидит всё, что синхронизируется.

- не выкладывай его в переписках и скриншотах;
- если он всё же ушёл — выйди из облака в настройках и войди заново: старый код
  перестанет работать.

Скрипт кладёт код в связку ключей Scriptable, чтобы не спрашивать его каждый
раз, и хранит последнюю копию данных рядом с собой — без сети виджет покажет её
и честно подпишет, что она вчерашняя.

## Что виджет считает занятым днём

Только то, что лежит на дате явно: незакрытые квесты, несделанные тренировки,
рабочие карточки с днём работы, задания учёбы со сроком, посты с днём выхода.

Расписания — занятия, пары, повторяющиеся тренировки — сюда не тянутся: их
пересчёт это половина приложения, и ошибиться в нём на домашнем экране хуже,
чем не показать. Их видно в самом планере.
