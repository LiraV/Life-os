# Handoff: «Жизнь в одном месте» — личная операционная система

## Overview
Мобильное приложение — «личная ОС» для девушки 20+, ведущей несколько параллельных жизненных треков (работа в e-retail, диплом бизнес-школы, магистратура fashion & luxury, блог, конный спорт, вокал, итальянский, стрип-пластика, зал). Главная механика: мягкая RPG-геймификация («я — персонаж симс»), связь целей год → квартал → месяц → неделя → день, кривая энергии совы (пик вечером, сон 10ч), ИИ-«Летописец», который наблюдает за пользователем и адаптирует приложение, и полный отказ от стриков/чувства вины — вместо этого «недели отдыха» после больших этапов.

Ключевые принципы продукта (важно сохранить при реализации):
- **Без вины**: пропуск ничего не отнимает; прогресс только накапливается; перенос задач — нейтральное действие.
- **Энергия-first**: день строится от кривой энергии (сова: разгон утром, пик 19:00–23:00); тяжёлые задачи — на пик.
- **«Зачем» у каждой задачи**: цепочка задача → цель месяца → квартал → тема года всегда видима.
- **ИИ прозрачен**: каждая правка Летописца видима и отменяема; цели он не меняет никогда.
- **Недели отдыха**: после победы над «боссом» (крупным этапом) приложение само предлагает паузу треков роста.

## About the Design Files
Файлы в этом пакете — **дизайн-референсы, созданные в HTML** (интерактивный прототип + вайрфреймы). Это НЕ production-код: задача разработчика — **воссоздать эти дизайны в целевом стеке** (React Native, Flutter, SwiftUI/Kotlin — по выбору команды; для MVP разумен React Native или Flutter из-за кроссплатформенности), используя паттерны и библиотеки этого стека. HTML-файлы служат источником точных цветов, отступов, копирайтинга и логики поведения.

- `Prototype.dc.html` — **основной референс**: рабочий интерактивный прототип (хай-фай) со всей логикой состояний. Логика написана как React-класс (`class Component`) внутри файла — state, обработчики и производные значения читаются напрямую из кода.
- `Wireframes.dc.html` — история исследования: 8 раундов вайрфреймов (лоу-фай) + хай-фай экраны раундов 7–8. Полезен для экранов, не вошедших в прототип (настройки, редакторы, онбординг-шаги, механики сфер: питание-«зелья», казна, спорт-статы).
- `support.js` — рантайм прототипа, не относится к дизайну, в реализацию не переносится.

## Fidelity
- `Prototype.dc.html` — **high-fidelity**: финальные цвета, типографика, отступы, копирайтинг и интеракции. Воссоздавать близко к пикселю.
- `Wireframes.dc.html`, раунды 1–6 — **low-fidelity** (структура и флоу); раунды 7–8 — high-fidelity в той же стилистике, что и прототип.

## Screens / Views

### Навигация
- **Нижний бар** (5 пунктов, только ежедневное): `☰ Ещё · День · Планы · Внутри · Я`. Активный пункт — белый текст на терракотовой пилюле `#8e2b32`.
- **☰ Ещё** открывает **левый drawer** (236px, фон `#f7ecdf`, slide-in 220ms ease-out): шапка с аватаром/уровнем, пункты Сферы, Привычки, Здоровье, Дневник, Тесты, Настройки. Активный пункт — рамка `1.5px solid #dcb3a6`. Когда открыт раздел из drawer, в баре подсвечен ☰.

### 1. Онбординг (3 шага)
1. **Привет** — заголовок «Вся жизнь — в одном месте», иллюстрация (illustration_01), карточка «Создаём персонажа» (имя + аватар), CTA «Начать · 3 минуты», ссылка «пропустить онбординг».
2. **Тело и ритм** — 4 карточки: слайдер «Сон» (6–11ч, шаг 0.5, дефолт 10), пилюли «Хронотип» (Жаворонок/Сова/Плавает), слайдеры «Интроверсия» (люди↔тишина) и «Активность» (покой↔движение). Значения живо меняют подписи-теги.
3. **Знакомься: ты** — черты-пилюли (хронотип, Спринтер, Перфекционистка, «? ? ?»), карточка «Я уже подстроилось» (фокус-блоки зависят от хронотипа: сова → «после 18:00»), AI-пузырь про дальнейшее обучение. CTA «В первый день →».

### 2. День (главный экран)
- Шапка со стрелками `‹ ›` — листание вчера/сегодня/завтра (диапазон ±1 день; крайние стрелки opacity .35 + disabled). У каждого дня свои задачи и свой комментарий Летописца.
- **Карточка энергии**: столбчатая мини-диаграмма кривой дня (6 столбцов, пиковые — терракот), под ней слайдер «энергия сейчас» (0–100). Значение меняет ярлык (на нуле / раскачиваюсь / огонь) и текст совета Летописца (низкая → предлагает облегчить вечер; высокая → подтверждает план).
- **Квесты дня** (карточки): чекбокс-скругление, время, название, тег сферы/«босс ★». Тап по чекбоксу — done (зачёркивание, opacity .65, чекбокс заливается терракотом). Особые реакции: «Зал» done → через 350ms всплывает шторка рефлексии; «Глава 2» done → тост «Босс недели повержен ✦». Ссылка «настроить ›» открывает шторку редактирования.
- **AI-пузырь** с советом дня.

### 3. Планы (Неделя / Месяц / Год)
Переключатель-пилюли + у каждого горизонта стрелки `‹ ›` (диапазон ±1 период):
- **Неделя** (33/34/35): текущая — карточка «Босс: черновик главы 2» (прогресс 2/3, «изменить ›»), задачи по сферам, AI «Вс — планёрка со мной». Прошлая — итог («Закрыто 8 из 10…»), будущая — «Пока пусто. Соберём в воскресенье». Правится только текущая.
- **Месяц** (Июль/Август/Сентябрь): 3 цели-карточки с прогрессом, тегом «→ Q3» и «изменить ›» (открывает шторку цели). Прогресс цели «Сдать главу 2» вычисляется из чек-этапов в Сферах (34% + 33% за черновик + 33% за отправку). Дашед-карточка про неделю отдыха.
- **Год** (2025/2026/2027): «2026 · „Свой голос"», иллюстрация, карточки кварталов: Q3 активен с прогрессом, Q4/Q1'27/Q2'27 приглушены.

### 4. Сферы (из drawer)
Грид 2×3 плиток: Обучение (древо), Работа (квесты), Блог (ферма идей), Спорт (статы), Питание (зелья), Бюджет (казна) + строка «Хобби · коллекция». Каждая плитка: обложка-иллюстрация 70px с бейджем механики, название, статус (живой: «глава 2 сдана ✓», «пост опубликован ✓»). Открываются в прототипе две:
- **Обучение · древо**: главы как ветки; глава 1 пройдена (opacity .75), глава 2 — «босс недели» с чек-этапами (План ✓ / Черновик / Отправить научнику). Оба этапа закрыты → AI-пузырь «Босс повержен! Предлагаю неделю отдыха» с выбором «Да, беру неделю / Продолжаю» (выбор — тост, состояние restTaken).
- **Блог · ферма**: иллюстрация, 3 стадии идей (росток → бутон → цветок «готов!»), «грядка недели», CTA «Опубликовать „про Милан" · Письмо +20» → двигает цель месяца (1/4 → 2/4), «жемчужину дня» и AI-реакцию.
Остальные плитки — тост «В полной версии»; их механики детально описаны в `Wireframes.dc.html` #8b (питание-зелья с баффами и водой, казна с 4 статьями и квестом-накоплением, спорт со статами Сила/Гибкость/Дух).

### 7. Внутри (Чат / Тесты / Дневник)
- **Чат с Летописцем**: AI-пузыри (градиент терракот, radius 20/20/20/6) и ответы пользователя (крем, radius 20/20/6/20, справа, max-width 82%). Диалог — стейт-машина из 3 стадий с быстрыми ответами-пилюлями; ответ добавляет сообщение пользователя сразу и AI-ответ через 550ms. Ветка «Да, вокал в четверг» ставит vocal=true → на экране «Я» растут Творчество и Артистка + тост.
- **Тесты**: полка (Мотивация — активен; Хронотип точнее; Ценности — пройден; Стресс-реакция — 🔒 «после 2 недель дневника»). Принятие добавляет тег черты на экран «Я».

## Interactions & Behavior
- Все переключатели — пилюли; активная: `background:#a63a35; border-color:#a63a35; color:#fff6ee`.
- Стрелки периодов: диапазон ±1 (день, неделя, месяц, год, месяц привычек); крайняя стрелка `opacity:.35; pointer-events:none`.
- Кнопки: hover — `translateY(-1px)`, active — `scale(.98)`; transition 150ms.
- Drawer: slide-in слева 220ms ease-out; закрытие — тап по оверлею.
- AI-ответ в чате — задержка 550ms после ответа пользователя (имитация набора; в проде — стрим).
- Рефлексия всплывает через 350ms после закрытия «Зала».
- Слайдер энергии — нативный range, accent `#a63a35`.
- Каскадные реакции (важно сохранить): публикация поста → цель месяца + жемчужина; чек-этапы главы → прогресс цели и статус плитки; вокал из чата → потребности/роли; тест → черта → теги профиля.

## State Management
Единый store (Redux/Zustand/Riverpod). Ключевые сущности из прототипа:
- `user`: имя, хронотип, сон (ч), интроверсия, активность, черты (массив, растёт), уровень.
- `quests` по дням: {id, time, title, tag, done}; `dayIdx` (просмотр дней).
- `goals` месяца: прогресс частично вычисляемый (из этапов сфер); `weekOff/monthOff/yearOff` — смещения периодов.
- `spheres`: статусы и внутренние состояния (draft/sent, publishedPost, restTaken).
- `habits`: {name, days[7]} + помесячные агрегаты; `habMode`, `habMonthOff`.
- `health`: цикл (день фазы), замеры (вес/талия/бёдра/сон).
- `chat`: [{who, text}], `stage` (стадия диалога); `vocal` — флаг каскада.
- `test`: testOn/testStep/testFin/trait; `diary`: производная коллекция; `energy`; `toast`; `drawerOpen`; шторки (sheet/goalSheet/refOpen).
Персистентность: локально (AsyncStorage/SQLite) + синк. ИИ-слой: LLM с доступом к чекинам/рефлексиям/дневнику по разрешениям из настроек; все его правки — через журнал с undo.
