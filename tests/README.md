# Проверки

103 набора. Каждый — отдельный файл, который поднимает Chromium, открывает
приложение и ведёт себя как человек: тыкает кнопки, вводит числа, перезагружает
страницу и смотрит, что получилось. Ни один не заглядывает во внутренности —
кроме `logic.mjs`, который наоборот спрашивает модули напрямую.

## Как запустить

Нужен Node и Playwright с Chromium:

```sh
npm i -D playwright && npx playwright install chromium
```

Playwright ищется сам — в проекте, глобально или по пути из `PLAYWRIGHT`.

```sh
./tests/run.sh --fast     # ~45 наборов, около трёх минут
./tests/run.sh --all      # все 103, около восьми минут
./tests/run.sh nav tabs   # только названные
JOBS=6 ./tests/run.sh --all   # больше параллели, если ядер хватает
```

Сервер поднимается сам: один на корень репозитория, второй отдаёт приложение из
подкаталога — так же, как GitHub Pages отдаёт его по адресу `/Life-os/`.

Упавшие наборы печатают первую строку с ошибкой, а полный вывод складывают в
`/tmp/failed/<набор>.full`.

## Что где

`gate` — воротца: приложение открывается, консоль чистая, ничего не потеряно.
С него начинается любой прогон.

`mig`, `mig6`, `mig7`, `migtag`, `migmod`, `rescue` — переезд данных со старых
версий и спасение нечитаемого сохранения. Самое важное: эти проверки стоят между
человеком и потерей данных.

`logic` — не экраны, а вычисления: реестр источников для динамических целей,
арифметика остатка, живучесть экранов на вкладке из старой версии.

`nav`, `tabs` — навигация: меню отвечает «где я» на каждом адресе, «назад»
возвращает откуда пришли, вкладка живёт в адресе.

Остальные названы по разделу: `day`, `budget`, `sport`, `blog`, `free`, `biz`…

## Правила, выученные на своих ошибках

- **Ждать состояние, а не миллисекунды.** `waitForTimeout(300)` проходит на
  спокойной машине и мигает под нагрузкой. Ждать надо отрисованное меню,
  изменившийся адрес, догрузившуюся картинку.
- **Воркер в проверках выключен** (`serviceWorkers: 'block'`) — кроме тех, что
  проверяют сам воркер. Иначе его запросы к шрифтам висят мимо маршрутизации
  страницы и растягивают прогон вдесятеро.
- **Не копировать реализацию в проверку.** Однажды набор про кривую энергии
  повторил в себе код приложения вместе с ошибкой — и, разумеется, прошёл.
  Проверка должна знать ожидаемый ответ, а не способ его получить.
- **`.caps` в вёрстке поднимает буквы в верхний регистр**, поэтому поиск по
  тексту делается без учёта регистра, а `toLocaleString('ru-RU')` разделяет
  разряды неразрывным пробелом, а не обычным.
